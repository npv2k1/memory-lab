# Enrichment

Extension point sau chunking và trước indexing, dành cho entity/relation extraction và temporal metadata.

Chưa có implementation trong Phase 1; pipeline hiện đi trực tiếp từ chunking sang indexing. Khi có thuật toán cụ thể, thêm contract và implementation tại đây, giữ nguyên nguồn chứng cứ của chunks. Không gọi generative LLM mặc định.
